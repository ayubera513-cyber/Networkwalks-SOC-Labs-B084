# Networkwalks SOC Labs & Forensic Analysis

This repository contains forensic analysis, network traffic inspection, and protocol investigations for Networkwalks SOC Labs 1 through 6.

## 🛠️ Tools & Protocols Analyzed
- **Wireshark**: Packet capture, network stream reconstruction, audio playback.
- **Protocols**: HTTP, FTP, SIP, RTP, TCP, ARP, DNS.
- **Forensic Focus**: Brute-force detection, authorization extraction, VoIP security.

## 📁 Repository Navigation
- `Lab-1/`: HTTP Traffic Analysis & Authorization
- `Lab-2/`: Web Server Traffic & Payload Inspection
- `Lab-3/`: Network Reconnaissance & Port Scanning
- `Lab-4/`: FTP Brute-Force & Credentials Recovery
- `Lab-5/`: VoIP Signalling & SIP Inspection
- `Lab-6/`: VoIP Audio Replay & SRTP Encryption
